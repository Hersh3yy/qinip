Teamwork

A kitchen with four cooks

Qinip does several jobs at the same time. Each cook has one job and passes notes through a hatch. Programmers call the cooks threads and the hatch a channel.

Screen cook

Redraws the window 20 times a second while music plays.

Speaker cook

Must never wait. If it is late, you hear a click.

Listener cooks

Work out beat and key in the back, so the screen never freezes.

Doorbell cook

Hears your keyboard's play and pause keys.

Where the kitchen idea stops: real cooks can chat and help each other. These helpers only pass written notes, which keeps them from bumping into each other. Ask Nami: why must the speaker cook never be kept waiting?
