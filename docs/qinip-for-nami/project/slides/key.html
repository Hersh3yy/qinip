Which key is the song in?

1. Count how much of each of the 12 notes (C, C#, D … B) the song uses.

2. Every key has a fingerprint: some notes are used a lot, some hardly.

3. Compare the song with all 24 fingerprints (12 major, 12 minor). Best match wins.
